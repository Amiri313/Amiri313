## 🚀 Featured Project

### Facial Emotion, Age Group & Gender Prediction

An end-to-end computer vision application combining **CNNs, MobileNetV2 transfer learning, OpenCV face detection, and Streamlit**.

- 🎭 7-class facial emotion recognition
- 🎂 Age-group prediction
- 👤 Gender prediction
- 📷 Real-time local webcam inference
- 🌐 Browser-based Streamlit application
- 📊 Model evaluation, confusion matrix, training curves, and documented limitations

**Validation results:** Emotion 59.4% · Age Group 58.1% · Gender 87.2%

🔗 **[Live Demo](https://fer-age-gender-emotion.streamlit.app/)** · 💻 **[GitHub Repository](https://github.com/Amiri313/FER-Age-Gender-Emotion-Project)**
